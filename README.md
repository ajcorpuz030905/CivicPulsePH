# CivicPulse PH — Static Website

This folder contains a static HTML/CSS/JavaScript version prepared for GitHub Pages.

## Publish with GitHub Pages
1. Upload the CONTENTS of this folder (not the ZIP itself) to the root of the `CivicPulsePH` GitHub repository.
2. Make sure `index.html` is at the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, branch `main`, folder `/(root)`, then Save.
5. Wait for deployment and open the URL GitHub Pages provides.

Note: ASP.NET MVC/C# server-side functionality is not included in static hosting. Any form that previously depended on a server needs a separate form backend to save submissions.
